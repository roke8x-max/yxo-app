## ⚠️ 三条最容易踩的

1. **退舱行**：批量路径必须排除它（最容易被"按班列改发班时间"误伤）；人工手动可以删，但系统不许替人删
2. **价格维护**：读 `price_config.json` 失败会**静默返回空配置**，此时添加一条并保存会**把整个价格文件覆盖成只剩这一条**
3. **前端编辑**：退舱行只允许改「备注」，其余单元格必须挡住
