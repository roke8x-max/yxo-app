# 模块：订舱数据管理平台（主站，:5011）

> 三大支柱里的**第二根**。同事日常在用的就是这个。
> ⚠️ **它的代码就在仓库根目录**（`app.py` / `templates/` / `static/` …），没有独立目录——所以本文件放在 `docs/` 下。

---

## 1. 它是什么

浏览器里的 **Excel 式表格 + 本地 SQLite**，用来替代飞书多维表。

**✅ 核心价值是「一站式看所有数据」**（毛骁洋 2026-10-06 明确）。同事愿意用它，是因为它替掉了以前凌乱的 WPS 在线表。**任何改动的优先级，都应该按"对查看体验的影响"来排，而不是按"功能多少"。**

**谁在用**：4 名内部同事（毛骁洋 / 冯茜 / 杨雅雯 / 韩文豪），内网经 nginx 反代访问 `http://<内网地址>:5000/yxo/`。

---

## 2. 页面与后端

| 页面 | 干什么 |
|---|---|
| `index.html` | **订舱主表**（筛选 / 排序 / 看板 / 统计 / 单元格编辑 / 回收站入口） |
| `manifest.html` | 舱单导入（空跑差异 → 人工确认 → 应用 / 回退） |
| `tuoshu.html` | 托书生成 |
| `admin.html` | 系统管理（价格维护 / 选项维护 / 服务状态 / 转发日志） |

**前端形态**：服务端渲染的**页面壳** + 原生 JS。`static/app.js` 是单文件大文件；**无框架、无构建工具**——"改完刷新即生效"是**被珍视的性质**，不要引入 npm / 打包链。

| 后端文件 | 职责 |
|---|---|
| `app.py` | 主服务：建表迁移、查询、写入、回收站、导出、算价、舱单/托书接入 |
| `admin_api.py` | 管理页 API（价格维护、配置表、服务状态、转发日志） |
| `manifest_engine.py` | 舱单导入引擎（纯逻辑，无 Flask 依赖） |
| `tuoshu_engine.py` | 托书 Excel 生成 |
| `import_excel.py` | Excel 台账导入（**已决定下线**，见 §6） |
| `config.py` | 业务配置：字段定义、公司、路由映射、权限开关 |
| `errors.py` | 统一错误处理 |

## 4. 数据

| 库 | 位置 | 关键表 |
|---|---|---|
| `yxo.db` | 生产 `D:\YXO_DATA\yxo_app\data\` | `records`（订舱真源）、`field_options`、`train_meta`、`tracing_log`、`tracing_snapshot`、`update_log`、`import_batch`、`user_state`、`meta_kv` |
| `auth.db` | 主站 `data/` | 权限模块专用（见 `auth/README.md`） |

> ⚠️ **两个 `bot_config` 不是一回事**：`init_bot_config.py` 建的是 **`yxo.db` 内**的表（主站后台用）；`mailbots_next/data/bot_config.db` 是**独立的机器人配置库**。**勿混库。**

**个人视图状态**：每个人的筛选 / 看板标签 / 排序按登录身份存 `user_state` 表（`/api/state`），**互不干扰，且已经实现**——不需要再设计个性化。

## 7. 运行与部署

```powershell
# 本机
venv\Scripts\python.exe app.py     # 或双击 start.bat（自动建 venv、查端口、开浏览器）
# → http://localhost:5011
```

```powershell
# 生产（在服务器 D:\YXO_DATA\yxo_app）
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -DryRun   # 先演习
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1           # 真部署
powershell -ExecutionPolicy Bypass -File scripts\rollback.ps1         # 出事回滚
```

⚠️ **数据库不会自动回滚**（脚本只把命令打出来）。确实要恢复时**先问毛骁洋**。

## 8. 已知坑（主站相关）

| 坑 | 说明 |
|---|---|
| **退舱记录** | 见 `docs/退舱记录处理约定.md` —— **主站的三条写路径目前没有守卫，是待修缺口** |
| 权限模块的观察期 | 开关 `=0` 时注入 `system` 身份 ⇒ `/api/state` 的个人状态会被 4 人共用。**部署权限模块前先决定观察期的身份口径** |
| **翻权限开关的前置** | 会打断舱单页（`manifest.html` 缺 CSRF）——见 `auth/README.md` §5 |
| `start.bat` 装的依赖不全 | 它只装 flask + openpyxl；新机器照它装可能起不来 |
| 导出产物不清理 | `data/export_*.xlsx` 只增不减 |
| 并发写 | `get_db` 未设 `busy_timeout`，而同一个 `yxo.db` 同时被主站与邮件机器人写 |
