## 背景与口径（自包含）

主站的月份快捷按钮条此前按「台账月份」归月（`monthOf()` 优先取 `台账月份`，为空回退 `发班时间`）。洋定：**月份筛选只看班列发运时间（库字段 `发班时间`）的月份**；「台账月份」退为数据统计辅助字段，其写入/回填语义一律不动。

空值口径（洋 2026-10-16 拍板方案 A）：`发班时间` 为空的记录 `monthOf` 返回 `""`——**不归入任何月份按钮，只在「全部」下可见**，不做台账月份回退。

月份筛选是纯前端本地过滤（一次拉全量 `api/rows`，后端无月份参数），**本任务后端零改动、不碰 `auth/`**。

## 任务（全部改动就这一处函数体）

`static/app.js` 的 `monthOf()`（34cfdb6 上在 532-539 行），整个函数替换为：

```js
function monthOf(r) {
  // 月份筛选口径（2026-10-16 洋定）：按班列发运时间（发班时间）归月。
  // 「台账月份」退为数据统计辅助字段，不再参与月份筛选。
  // 发班时间为空的记录不归任何月份，只在「全部」下可见（方案A）。
  const s = String(r["发班时间"] || "").trim();
  const m = s.slice(0, 7).replace(/\//g, "-");
  return /^\d{4}-\d{2}$/.test(m) ? m : "";
}
```

- 保留函数名与所有调用点（表格过滤 `passFilter`、月份条 `monthsFromData`、默认月 `pickDefaultMonth`），零改动。
- `replace(/\//g,"-")` 保留，兼容历史斜杠日期格式。
- 函数注释按上面原样带上（口径出处写清楚，防止后人又改回去）。
