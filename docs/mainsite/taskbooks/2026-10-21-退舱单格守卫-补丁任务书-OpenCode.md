## 二、P1（必须）：右键单格粘贴 → 退舱行假成功 + 本地脏值

**位置**：`static/app.js` 的 `pasteToRow()`，单格分支。当前（`app.js:1815-1829`）：

```js
    const rec = DATA.find((x) => x.id === id);
    if (!rec) return;
    const cols = userColumns();
    const target = (_ctxField && cols.find((c) => c.name === _ctxField)) || cols[0];
    if (!target) return;
    if (String(rec[target.name] || "") === raw) { toast("内容相同，无需粘贴"); return; }
    ...
    rec[target.name] = nv;
    saveCell(id, target.name, nv);
    renderActive();
    toast("已粘贴到「" + target.name + "」");
```

**改法**：在 `if (!target) return;` 之后、任何"内容相同"判断之前插入一行：

```js
    if (isCancelLocked(rec, target.name)) { toast("退舱记录只允许修改「备注」和「状态」"); return; }
```

要点：
- 必须放在 `rec[target.name] = nv;` **之前**（放后面就来不及了，本地已被写脏）。
- 用 `isCancelLocked`（单格口径，备注/状态放行），**不要**用 `isCancelBatchLocked`。
- 后面的 `saveCell` 守卫保留不动（双保险），但正常路径不会再走到"被拦"的分支。

**改完后应满足**：右键把「箱号」粘到退舱行 → 只弹一次「退舱记录只允许修改「备注」和「状态」」，**本地 `DATA` 不变**、**无 "已粘贴到…" 提示**、无请求。

```js

```

**改成**（与 `applyBulkSet` 的写法对齐）：

```js
  if (!edits.length) {
```

**改完后应满足**：在退舱行上右键粘贴一列「箱号」→ toast「退舱记录不可修改，已跳过 1 个单元格」；不含退舱行时仍是原提示。
