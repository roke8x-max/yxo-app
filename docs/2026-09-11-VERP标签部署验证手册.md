## 一、这是测什么（大白话）

要解决的问题：**转发出去的邮件被对方服务器退回（退信/NDR）时，我们得知道"是哪一封被退了"，才能自动重发。**

麻烦点在于：退信是对方服务器发给"发件人"的，可我们一封邮件会转发给好几家客户，**怎么区分退信属于哪一封？**

两种办法：

- **办法 1（VERP，代码里的默认做法）**：寄的时候把"退信回执地址"写成
  `mailbots-bounce+<16位hex>-<8位hex>@cqtransit.com`，那串码就是这封邮件的身份证（forward_id）。
  退信回来一看收件人地址里的码，就知道是哪一封了。
  **前提两条**：① 邮箱服务商支持"加号子地址"（`+` 后面是标签，邮件仍投进 `mailbots-bounce@` 这个邮箱）；② 允许我们**用"不是自己登录账号"的地址当回执地址**。
- **办法 2（兜底）**：回执地址就老实写 `mailbots-bounce@cqtransit.com`，但在转发邮件里塞一个隐藏信头 `X-YXO-Forward-Id: <身份证>`，指望**退信里会把原信（含这个信头）带回来**。
  前提：对方 MTA 愿意回传原信内容（多数会，但不保证）。

**本次验证就是回答：办法 1 在 cqtransit.com（阿里云企业邮箱）到底行不行。不行就把配置改成 `BOUNCE_USE_VERP=0` 走办法 2。**

> ⚠️ 拿到结论前**不要改任何生产配置**。

## 二、前置条件（3 件事）

1. **建一个专门收退信的邮箱**：`mailbots-bounce@cqtransit.com`
   - 阿里企业邮箱后台 → 邮箱管理 → 新建账号（或建**别名/邮件组**指向你自己的邮箱）。
   - **必须开启 IMAP**（后台"客户端设置"里开；部分企业邮默认只开 POP）。
   - 记下它的**密码 / 客户端授权码**。
2. **确认 SMTP / IMAP 地址**（脚本默认按阿里企业邮箱常见值填，**以贵司后台"客户端设置"页为准**）：
   SMTP `smtp.qiye.aliyun.com:465(SSL)` / IMAP `imap.qiye.aliyun.com:993(SSL)`
3. 一个**能发信的账号**（如 `maoxiaoyang@cqtransit.com`）及其密码/授权码。

## 三、跑这个脚本

存成 `verp_probe.py` → **⚠️ 先把"改成真值"的 9 行替换掉**（别原样复制，密码字段是占位文字）→ `python verp_probe.py`

```python
# -*- coding: utf-8 -*-
"""VERP 退信标签验证：4 个探测，最后直接给出要回填的 6 个数。"""
import imaplib, smtplib, ssl, time, uuid
from email.mime.text import MIMEText

# ==================== ⚠️ 下面 9 行改成真值 ====================
SMTP_HOST       = "smtp.qiye.aliyun.com"                 # 以邮箱后台为准
SMTP_PORT       = 465
IMAP_HOST       = "imap.qiye.aliyun.com"                 # 以邮箱后台为准
IMAP_PORT       = 993
SENDER_ACCOUNT  = "maoxiaoyang@cqtransit.com"            # 发信账号
SENDER_PASSWORD = "改成该账号的密码或客户端授权码"
BOUNCE_ACCOUNT  = "mailbots-bounce@cqtransit.com"        # 收退信邮箱（须已建、已开IMAP）
BOUNCE_PASSWORD = "改成该邮箱的密码或客户端授权码"
BAD_RECIPIENT   = "no-such-user-abc123@cqtransit.com"    # 故意不存在的收件人，用来触发退信
WAIT_SECONDS    = 150                                    # 等退信回来的秒数，可加大
# ===========================================================

FID = f"{uuid.uuid4().hex[:16]}-{uuid.uuid4().hex[:8]}"   # 模拟 forward_id（纯hex-纯hex）
TAG = uuid.uuid4().hex[:8]
VERP_FROM = f"mailbots-bounce+{FID}@cqtransit.com"
ACCEPTED = {}


def _send(envelope_from, to_addr, subject, extra_header=None):
    msg = MIMEText("probe body", "plain", "utf-8")
    msg["Subject"] = subject
    msg["From"] = SENDER_ACCOUNT
    msg["To"] = to_addr
    if extra_header:
        msg[extra_header[0]] = extra_header[1]
    with smtplib.SMTP_SSL(SMTP_HOST, SMTP_PORT,
                          context=ssl.create_default_context(), timeout=30) as s:
        s.login(SENDER_ACCOUNT, SENDER_PASSWORD)
        return s.sendmail(envelope_from, [to_addr], msg.as_string())


def try_send(key, envelope_from, to_addr, subject, extra_header=None):
    try:
        ok = not _send(envelope_from, to_addr, subject, extra_header)
        print(f"[{key}] envelope=<{envelope_from}> ->", "✅ SMTP 接受" if ok else "❌ refused")
    except Exception as e:
        ok = False
        print(f"[{key}] envelope=<{envelope_from}> -> ❌ 被拒：{type(e).__name__}: {e}")
    ACCEPTED[key] = ok
    return ok


def scan(account, password, needle, wait=WAIT_SECONDS, recent=30):
    print(f"      ...等 {wait}s 后查 {account}")
    time.sleep(wait)
    im = imaplib.IMAP4_SSL(IMAP_HOST, IMAP_PORT, timeout=60)
    im.login(account, password)
    im.select("INBOX")
    _, data = im.search(None, "ALL")
    hits = []
    for u in (data[0].split()[-recent:] if data and data[0] else []):
        _, d = im.fetch(u, "(RFC822)")
        if needle in d[0][1].decode("utf-8", "replace"):
            hits.append(u.decode())
    im.logout()
    return hits


def head(s):
    print("\n" + "=" * 62 + f"\n{s}\n" + "=" * 62)


# ---------- 探测 1：加号子地址通不通 ----------
head("探测 1  子地址（邮件能否投进 mailbots-bounce+标签@ ）")
try_send("p1", SENDER_ACCOUNT, f"mailbots-bounce+probe{TAG}@cqtransit.com", f"PLUS PROBE {TAG}")
r1 = scan(BOUNCE_ACCOUNT, BOUNCE_PASSWORD, f"probe{TAG}")
print("探测1 子地址:", "✅ 通（进了收信邮箱且标签还在）" if r1 else "❌ 不通")

# ---------- 探测 2：VERP 整链路 ----------
head("探测 2  VERP 整链路（自定义回执地址 + 真退信）")
r2 = []
if try_send("p2", VERP_FROM, BAD_RECIPIENT, f"VERP ROUNDTRIP {TAG}"):
    r2 = scan(BOUNCE_ACCOUNT, BOUNCE_PASSWORD, FID)
    print("探测2 退信回到收信邮箱且带身份证:", "✅ 是" if r2 else "❌ 否")
    if not r2:
        print("      → 顺带查发信账号自己的收件箱（判断回执地址是否被服务商改写）：")
        print("        发信账号收件箱里找到退信:", "是（envelope 被改写）" if scan(SENDER_ACCOUNT, SENDER_PASSWORD, FID) else "否")

# ---------- 探测 3a / 3b：兜底方案的两种回执地址 ----------
head("探测 3  兜底方案（靠 X-YXO-Forward-Id 信头）")
r3a = []
if try_send("p3a", BOUNCE_ACCOUNT, BAD_RECIPIENT, f"FALLBACK-A {TAG}", ("X-YXO-Forward-Id", FID)):
    r3a = scan(BOUNCE_ACCOUNT, BOUNCE_PASSWORD, FID)
    print("探测3a 退信回收信邮箱且带信头:", "✅ 是" if r3a else "❌ 否")
r3b = []
if try_send("p3b", SENDER_ACCOUNT, BAD_RECIPIENT, f"FALLBACK-B {TAG}", ("X-YXO-Forward-Id", FID)):
    r3b = scan(SENDER_ACCOUNT, SENDER_PASSWORD, FID)
    print("探测3b 退信回发信账号且带信头:", "✅ 是" if r3b else "❌ 否")

# ---------- 汇总 ----------
head("汇总（把这 6 个数回给芙蕾雅）")
print("1) 子地址通                :", bool(r1))
print("2) 接受自定义回执地址      :", bool(ACCEPTED.get("p2")))
print("3) 退信落收信邮箱且带码    :", bool(r2))
print("4) 收信邮箱可当回执(p3a)   :", bool(ACCEPTED.get("p3a")), "| 退信带信头:", bool(r3a))
print("5) 发信账号可当回执(p3b)   :", bool(ACCEPTED.get("p3b")), "| 退信带信头:", bool(r3b))
print("6) 本次 forward_id 示例    :", FID)
```

## 四、怎么读结论 → 该配什么

| 探测1 子地址 | 探测2 自定义回执 | 退信落点 | 结论 | BOUNCE_USE_VERP |
|---|---|---|---|---|
| ✅ | ✅ 接受 | ✅ 收信邮箱 + 带码 | **VERP 可用（最优）** | **1**（当前默认，不用改） |
| ✅ | ✅ 接受 | ❌ 发信账号 | 回执地址被**改写** | 0 |
| ✅ | ❌ 被拒 | — | 不许用非登录账号当地址 | 0 |
| ❌ | — | — | 不支持加号子地址 | 0 |

**走 VERP=0 时关联改靠 `X-YXO-Forward-Id` 信头 → 所以探测 3 必须至少有一个 ✅，否则两种办法全失效，回来找芙蕾雅另设计。**

### ⚠️ 关键连锁风险（务必先看这条）

VERP=0 时，回执地址 = `BOUNCE_ADDRESS`。如果贵司邮箱**也不允许** `mailbots-bounce@` 当回执地址（探测 3a 被拒），那唯一能用的回执地址就是**发信账号自己**（探测 3b）。

而这会带来一个副作用：**转发是用 4 位同事的账号分别发的**（毛骁洋/杨雅雯/冯茜/韩文豪），回执地址若等于各自的发信账号，**退信就会散落到 4 个不同的收件箱**——而现在的 NDR 轮询只盯**一个**邮箱（`BOUNCE_IMAP_USER`），就会漏掉大部分退信。

**如果落到这个分支，先别自行决定**，把探测 3a/3b 的结果回给我，我们从三条里挑：
- (a) 转发统一改用一个专用发信账号（退信都进它）；
- (b) 找阿里企业邮箱开通"允许 `mailbots-bounce@` 作为发件人/回执地址"（有企业邮支持）；
- (c) 让小叽轮询 4 个邮箱（改造量最大，最后选）。

## 五、常见卡点

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| `SMTPAuthenticationError` | 密码错 / 用了登录密码而非**客户端授权码** / 没开 SMTP | 后台开 SMTP，生成客户端授权码 |
| `LOGIN failed` 或 select 失败 | 该邮箱没开 IMAP | 后台开启 IMAP 后重试 |
| 探测1 找不到邮件 | ①没开子地址支持 ②进了**垃圾邮件** | 先查"垃圾邮件"文件夹；仍无 → 判定不通 |
| 探测 3 找不到 | 退信还没回来 | `WAIT_SECONDS` 加到 300~600 再跑，或隔天手动查 |
| 退信到了但不含身份证 | 对方 MTA 不回传原信 | 属 VERP=0 的风险点，务必告知芙蕾雅 |
| 应用里 `poll_bounces` 报 `unknown forward_id` | `BOUNCE_FOLDER` 指错（退信在"垃圾邮件"而非 INBOX） | 把 `BOUNCE_FOLDER` 指向正确文件夹 |
