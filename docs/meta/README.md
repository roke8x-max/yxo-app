## 💡 两条开发经验（旧 AGENTS.md「已知坑」救回）

> **① `grep` 在 Windows PowerShell / CMD 里不存在**
> 在 Windows 上自查代码位置，一律用 **Python AST 脚本**（且 `grep -A1` 本身也会漏检多行结构）。
> 这条是方法经验——丢了下次还得踩。

> **② 自查代码不要只 grep 名字**
> 判断"某同名模块是否真的被用到"，必须复现调用方的实际 `sys.path` 改写或真 import 一遍；
> 只 grep 名字、或只 `sys.path.insert(0, 仓库根)` 就 import，都会得到错误结论。
