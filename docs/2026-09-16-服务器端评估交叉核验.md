## 6. 对修法选项的更新

- **A（轮询）仍是首选，而且已被小叽实测验证**：它手动把开关开到 2 秒，**同一套代码全链路跑通**（搜信 → 读取 → 回调成功、IMAP 命令流干净）。⇒ 我原来的推荐得到独立验证。而且 `--poll-secs` 这个参数**已经在**，只差把它接到 `poll_fallback_secs` 上。
- **B（第三方库）的成本要上调**：我查了 `imaplib2` —— 它确有 `idle(timeout)`/`idle_done`，但调用约定是**异步/回调式**（`idle(callback=...)`），与现在的"阻塞三段式"不一一对应 ⇒ **不是"只多一个依赖"的插入式替换**，仍要重写 `_idle_once`。`imapclient` 同理（改用上下文管理器）。
- **新增 D：升级到 Python 3.14** 用官方 `with M.idle(duration=…)`。技术上可行，但要动生产运行时 + 重写调用，**本轮不建议**。
