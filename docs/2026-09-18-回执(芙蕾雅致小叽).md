**④ `WeComBot\server.py` 追加端点**（放在 `/health` 那段之后、启动块之前；顶部已有 `request` / `wecom_api` / `WECOM_USER_MAP` 的 import；另把 `NOTIFY_API_TOKEN` 加进 `from config import (...)` 那一行，并在文件顶部加 `import hmac`）：

```python
@app.route("/api/notify", methods=["POST"])
def api_notify():
    """供同机的 mailbots_next 调用：按姓名发企微通知。内部接口，必须带 token。
    body: {"name": "毛骁洋", "text": "...", "try_kf": true|false}"""
    tok = request.headers.get("X-Notify-Token") or ""
    if not NOTIFY_API_TOKEN or not hmac.compare_digest(tok, NOTIFY_API_TOKEN):
        return {"ok": False, "msg": "unauthorized"}, 401
    d = request.get_json(force=True, silent=True) or {}
    name, text = (d.get("name") or "").strip(), (d.get("text") or "").strip()
    if not name or not text or len(text) > 4000:
        return {"ok": False, "msg": "bad request"}, 400
    try:
        if d.get("try_kf") is False:
            # 只走应用消息，跳过微信客服通道。
            # 注意：WECOM_USER_MAP 是 {UserID: 姓名}（键=UserID），没有反向索引，
            # 所以按姓名查 UserID 必须反向查找——不要写 WECOM_USER_MAP.get(name)。
            uid = next((k for k, v in WECOM_USER_MAP.items() if v == name), None)
            if not uid:
                return {"ok": False, "msg": "unknown name"}, 400
            ok = wecom_api.send_app_text(uid, text)
            channel = "app"
        else:
            # 默认：保持现有双通道行为不变（notify_by_name 返回 (bool, 'kf'|'app'|'')）
            ok, channel = wecom_api.notify_by_name(name, text)
    except Exception as e:
        print(f"api_notify error: {e}")
        return {"ok": False, "msg": "internal error"}, 500
    return {"ok": bool(ok), "channel": channel}
```

> 逻辑约 18 行（含注释与 docstring 共 27 行）。两处**已替你核实过的前提**，照抄即可、别猜：
> - `config.py:96-101` 的 `WECOM_USER_MAP` 是 **`{UserID: 姓名}`**（键是 `MaoXiaoYang` 这类英文 UserID）；
>   想按姓名取 UserID **必须反向查找** —— 不能写 `WECOM_USER_MAP.get(name)`（会永远返回 `None`）。
