## 五、⚠️ 需洋拍板：登录框在 Edge 里没有眼睛了

```
static/style.css:1210   input[type="password"]::-ms-reveal, ::-ms-clear { display:none; }
templates/admin.html:73 同上
```

`input[type="password"]` 是全局选择器 ⇒ 除了我们加了自己眼睛的 5 个框，
**登录框 `loginPass`（`index.html:247`、`admin.html:114`）的 Edge 原生眼睛也被一起关掉了，而它没有替代品**。
（Chrome 本来就没有原生眼睛，不受影响；Firefox 也没有。）

这与你「输入密码时能看密码」的意图相反 —— 只是在登录框这一处。三个选项：

| 方案 | 改动量 | 结果 |
|---|---|---|
| **A（我建议）** 选择器收窄成 `.pw-wrap input[type="password"]::-ms-reveal` | 2 个文件各 2 行 | 登录框**恢复原生眼睛**（聚焦时出现，和改前一样），5 个框只有我们的眼睛 |
| B 给登录框也加我们的眼睛 | 再包 2 个 `.pw-wrap` + 2 个按钮 | 7 个框一致，但超出工单范围 |
| C 先合，登记以后改 | 0 | Edge 登录时看不到密码，直到以后修 |

我倾向 **A**：零风险、恢复原状、不改范围。要 A 的话，下一轮（或你直接改这 4 行）都行。
