### 🔴 我漏了一条：`/admin` 的「重置密码」弹窗常显且关不掉

```
templates/admin.html:52   .hidden { display:none; }                 ← 无 !important
templates/admin.html:56   .modal-mask { ... display:flex; ... }     ← 同特异性、在后 → 胜出
templates/admin.html:299  <div id="resetModal" class="modal-mask hidden">
```

⇒ `#resetModal` 的 computed `display` 是 `flex`，进页面就盖住整页，`closeResetPw()` 加 `hidden` 也压不过。
主站不受影响（`static/style.css:203` 带 `!important`，且 admin 页不引 style.css）。

**为什么没抓到**：这 16 条测试是 API/逻辑层的；A6/B8/B16 那三项视觉我标了"待实机"，但**弹层默认可见属于"读 diff 就能看出"的 CSS 特异性问题**，归到"等实机"是我判断错了。教训：**凡是新增/修改带 `display` 的弹层，先查同特异性规则的先后顺序，并加一条源码级断言。**
