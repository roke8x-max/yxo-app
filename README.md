# YXO 订舱数据管理（方案 A 正式版）

用「浏览器表格 + 本地数据库」替代飞书多维表：同事看到的是直观的 Excel/飞书式表格，
脚本直接读写同一份 SQLite 数据库（解决 WPS 调不动代码、飞书占资源/API 限额的问题）。

---

## 一、文件夹结构（很清楚，别改结构）

```
D:\YXO_DATA\yxo_app\
├── app.py            # 后端主程序（Flask + SQLite），一般不用看
├── config.py         # 业务配置：改这里就能改公司名/导入文件/字段（见第三节）

├── data\             # 数据库文件 yxo.db 自动生成在这里
├── start.bat         # 双击启动（自动检测是否已运行、自动开浏览器）
├── check_port.py      # 端口检测小工具（被 start.bat 调用，别删）

```

> 旧的原型在 `D:\YXO_DATA\yxo_web\`，已被本文件夹替代，互不影响。

---

## 二、怎么启动（你或同事第一次用）

1. **双击 `start.bat`**。
2. 它会自动打开浏览器访问 **http://localhost:5011**
   （同事通过 nginx 反代访问 **http://你们的地址:5000/yxo/**）。
   - 如果已经在运行，它会直接打开浏览器、不会再开一个，不会报错。
3. 关掉：直接关掉弹出的 python 窗口即可（或任务管理器结束 python）。

> 第一次会自己装运行环境，之后秒开。不污染你电脑的系统 Python。

## 三、给你的（改配置只需动 config.py）

| 想改什么 | 改 config.py 哪里 |
|---|---|
| 4 位同事的显示名字 | `USERS = ["阿渝", "同事二", "同事三", "同事四"]` |
| Excel 数据来源 | `IMPORT_FILE = r"D:\YXO_DATA\output\八月记录汇总.xlsx"` |
| 价格配置来源 | `PRICE_CONFIG = r"D:\YXO_DATA\MailBots\price_config.json"` |

| 看板可分组字段 | `GROUPABLE` |

改完重启 `start.bat` 生效。

**导入数据**：页面里点「导入 Excel」即可把最新 Excel 拉进来。
已存在的行（按客户编码匹配）只刷新基础字段，保留你填的箱号/草单等操作字段。

## 四、使用说明（给同事看，无权限限制，4 人都能改，同 WPS）

- **表格筛选**：点列头右侧 `⏷` 可下拉多选（选项随数据自动更新）；列下方「包含」框可输入关键字。多列条件同时生效（Excel 式）。
- **排序（多条件）**：点列名即可升序/降序切换；**按住 Shift 点多个列**可叠加多条件（例如先「发班时间」升序、再「客户编码」升序）。也可点工具栏「⇅ 排序」按钮，在面板里增删条件、设升/降序。
- **新增 / 删除（右键）**：在表格里**右键某一行**，可选「在上方插入新行 / 在下方插入新行 / 在末尾新增行 / 删除此行」；也可点工具栏「＋ 新增行」。删除会二次确认。
- **公司多选**：点「公司」可勾选多家，满足一人看几家客户。
- **个人筛选互不干扰**：右上「我是」选自己，你的筛选/看板标签/排序只属于你。
- **看板**：选分组字段生成列；点「＋新建标签」把某个条件存成标签栏，可 ✎ 编辑、× 关闭。
- **统计**：按当前筛选汇总单价（合计 / 平均 / 按公司 / 按月）。
- **序号**：每行左侧固定编号（随排序/筛选实时变化）。
- **编辑**：单元格直接点改，单箱价格为空时点「算价」自动填（复用现有价格表逻辑）。

## 五、给技术接管的备注（你不用管）

- 数据源：SQLite（单文件 `data/yxo.db`），脚本可随时读写，无需飞书 API。
- 反代：`F:\Docker\nginx\conf.d\yxo.conf` 的 `location /yxo/` 指向内网 `:5011`，复用现有公网 5000 端口，无需新增端口。
- 后续把现有 4 个同步脚本（sync_price / Database_Syncer / sync_to_subtables / 机器人）改为读本库即可彻底去飞书。
- 个人状态按用户名存 `user_state` 表；无登录鉴权（按你要求，4 人全可操作）。
