安全红线：① 绝不用 filebrowser 传代码 ② 绝不在 D 盘直接改代码 ③ 绝不直推 main ④ 敏感信息不入库 ⑤ AI 生成代码只进 dev，经 PR 审核后进 main
ZeroTier 解耦：关键链路（任务下发 → GitHub → PR → 审批 → 部署）100% 走公网，不依赖 ZeroTier。ZT 仅用于 SSH/RDP 远程通道，有 RustDesk/iNode 备份。
08-10 更新：任务队列从 SMB 改 GitHub tasks/；WeComBot :5001 复用为审批通道（无需新建穿透）；deploy.ps1 统一纳管多服务；分支命名强制连字符禁斜杠。

改造总原则：不改造旧版，按模块 greenfield 重优化；旧代码仅作避坑参考。代码纳入统一仓库，secrets/生产库/本地绝对路径绝不入库。
gate 定位收窄（08-10 更新）：只守「手写 LLM 调用」（WeComBot 免费模型 NLP），含 PII 脱敏 + 审计 + 跨模型 timeout fallback。agent 自身推理、opencode 内置免费模型由各自框架管理，不走 gate。
WeComBot 隔离更新：代码纳入统一仓库（wecombot/ 子目录），但 secrets.json、生产 yxo.db、服务器本地绝对路径绝不入库——改用 secrets.example.json 模板 + .gitignore 屏蔽 + config/ 读环境变量。
